# 题目证据变化下的自适应学习测查与选课建议

这是一个面向社区老年教育运营的本地分析原型，使用合成记录演示从业务记录到运营摘要的处理。项目把记录读取、统计口径和运营判断分开，便于核对原始事实与派生结果。

## 环境与使用

需要 Python 3.11 或更高版本，无第三方依赖。运行 `python3 -m unittest discover -s tests -v` 执行测试；运行 `python3 -m learning_adaptive_check.report` 查看合成数据摘要。所有记录均为本地合成数据，不包含个人信息。

## 现有行为

题库统计决定尺度与可用题；会话选题与停止消费技能不确定性并响应撤题；建议消费不同技能证据而非总分布尔值。

当前摘要只反映样例记录的基础汇总，不用于形成个体资格或运营承诺。SQLite 数据库在调用时创建于临时目录，原始 CSV 保持不变。
