# 题目证据变化下的自适应学习测查与选课建议

面向社区老年教育运营的本地分析原型，用合成记录演示从题库统计、进行中的自适应测查到选课建议的完整流程。项目把**原始事实**（题库统计、作答、撤题、固定题单历史成绩）与**派生判断**（校准、尺度族、技能状态、课程建议）分层，口径集中且全程留痕，便于工作人员核对每一条结论的依据。所有记录均为本地合成数据，不含个人信息；无第三方依赖，仅使用 Python 3.11 标准库。

## 环境与使用

```bash
python3 -m unittest discover -s tests -v     # 运行测试（50 个用例）
python3 -m learning_adaptive_check.report    # 查看合成数据端到端摘要
```

Docker：`docker build -t learning-adaptive-check .` 后 `docker run --rm learning-adaptive-check`；容器内跑测试：
`docker run --rm --entrypoint python3 learning-adaptive-check -m unittest discover -s tests -v`。

SQLite 数据库在调用时创建于临时目录，原始 CSV 保持不变。

## 数据（`data/`，合成数据）

| 文件 | 含义 |
| --- | --- |
| `skills.csv` | 技能、所需证据量、掌握线 |
| `items.csv` | 题目、技能归属、支持的无障碍呈现方式（text/large_print/audio） |
| `item_stats.csv` | 题目分呈现方式的历史作答计数 |
| `courses.csv` / `course_prereqs.csv` | 课程、是否带教、先修技能 |
| `legacy_scores.csv` | 固定题单历史成绩（读取即冻结，无任何改写路径） |

## 业务规则与模块对应

### 1. 题库统计：小样本不能凭偶然答对率判易（`calibration.py`）

- 每个（题 × 呈现方式）用 Beta-二项收缩估计正确率，样本越少先验影响越大，可信区间越宽；
- 样本量低于 `MIN_ATTEMPTS`（20）一律标记“校准不足”，难度只能是 `undetermined`，证据权重按样本量从 0.5 线性折减到 1.0；
- 容易/难题用**单侧后验概率**（阈值 0.85）判定，而不是裸答对率；规则化不完全 Beta 函数自行实现，无第三方依赖。

### 2. 跨呈现方式尺度：共用必须有桥接证据（`scales.py`）

- 同一题在多个呈现方式下都达到校准样本量、且后验均值最大差异 ≤ `BRIDGE_MAX_DIFF`（0.1）才构成“桥”，允许合并；
- 桥的连通分量形成尺度族（合成数据中 text 与 large_print 合族，audio 因难度差异显著独立成族），每条桥接通过/不通过都带原因留痕；
- 族内零样本新题借用弱信息族先验（等效样本量 4），不制造虚假确定性。

### 3. 自适应测查会话（`session.py`、`bank.py`）

- 会话绑定**单一尺度族**：构造期校验呈现方式，候选题只从族内取，提交侧再做防御性拒绝，禁止拼用互不兼容的尺度；
- 技能判断三态——**合格 / 未掌握 / 证据不足**：带 Beta(1,1) 先验，证据量达标且单侧后验概率越线才下合格/未掌握结论，否则一律证据不足；
- 选题按“覆盖缺口从大到小”优先保证必要技能被覆盖，同技能内按期望信息量（后验区间宽度）排序，并对历史曝光高的熟题降权轮换；高缺口技能题尽时顺延，所有技能题尽才停止；
- **题目耗尽绝不自动判通过**，只以 `CLOSED_INCONCLUSIVE` 收尾并点名不足的技能；
- 作答提交幂等：同题重复提交返回 `DUPLICATE_REJECTED`，不会产生或改写证据；每次选题、停止、撤题、重算都写入可解释的决策事件。

### 4. 测查进行中撤题（`bank.py`、`session.py`）

- **内容失效**（`content_invalid`）：该题在本会话的已作答证据标记剔除，相关技能立即重算，能否结束、选课资格随之重新判断；
- **正常下架**（`normal`）：撤题前作答保留有效，仅后续不再出该题；
- 撤题前无作答时只影响后续选题；撤题标记持久化，新会话也不能再选；
- 固定题单历史成绩独立存储、只追加不覆盖，撤题不改变其当时含义。

### 5. 选课建议（`recommendation.py`）

按**每个技能的证据**而不是总分布尔值分四类，并明确列出证据不足的具体技能：

- `ready` 有把握的先修资格；
- `needs_assessment` 需要补充测查（先列出具体技能）；
- `mentoring_only` 有技能未掌握但课程带教，可在带教支持下选择；
- `not_recommended` 未掌握且课程不带教。

历史通过的固定题单成绩作为**带出处的独立证据**（标注题单、日期、尺度标签）展示，不与自适应尺度混算；历史未通过不直接判未掌握，需补充自适应证据。

### 6. 持久化（`storage.py`）

SQLite 中 `responses`、`legacy_scores` 为只增事实表（撤题通过独立标记表表达，不删事实），决策事件单独留痕，跨会话曝光计数供新会话轮换使用。

## 边界与定位

当前摘要是合成数据上的规则原型，用于核对口径与流程，不用于形成个体资格或运营承诺；真实使用前需要用真实历史作答校准阈值（样本量门槛、桥接差异、掌握概率判据）并复核无障碍呈现方式的覆盖情况。
